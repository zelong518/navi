# 知乎常关注话题（模板）

复制成 `$NAVI_HOME/zhihu-topics.md` 再按自己的关注点改。`/navi-zhihu topic` 不带关键词时
读这份清单，逐个话题去搜。**这是你唯一需要维护的文件**，加删话题不用改 skill。

一行一个话题，`#` 开头的行是注释。可以写多个词（空格分隔）当作一次查询。
话题写得越具体，返回的越不水——「可观测性」比「运维」有用得多。

```
# 一行一个查询
可观测性 分布式追踪
故障定位 根因分析
```
